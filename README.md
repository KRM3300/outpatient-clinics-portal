# بوابة العيادات الخارجية | Outpatient Clinics Portal

بوابة داخلية موحدة لخدمات العيادات الخارجية — مستشفى الرس العام.

## الصفحات
| الصفحة | المسار |
|---|---|
| الصفحة الرئيسية (الخدمات، الدخول، إدارة المستخدمين) | `index.html` |
| طلبات المواعيد (الطوارئ والمتابعة) | `appointment-requests/` |
| إدارة تجربة المريض | `patient-experience/` |

الروابط القديمة (`test-live.html`، `secure-test.html`، `queue.html`) تحوّل تلقائيًا إلى الصفحات الجديدة.

## الهوية الموحدة
- كل الصفحات تستخدم ملف التنسيق `assets/portal.css` (الألوان، الخط، الترويسة، الأزرار، الحقول).
- أي تعديل في الألوان أو الخط يتم في أعلى هذا الملف فقط، فيظهر في جميع الصفحات.
- الشعار: `assets/logo.webp`، وأيقونة المتصفح: `assets/favicon.png`.
- الخط: IBM Plex Sans Arabic. الأيقونات: SVG مضمّنة من مجموعة Lucide.
- عند إضافة خدمة جديدة: انسخ ترويسة وتذييل إحدى الصفحات واربط ملف التنسيق نفسه.

## مبادئ المشروع
- صلاحيات موحدة على مستوى البوابة والخدمة والإجراء
- دعم العربية وRTL
- حماية البيانات من جهة الخادم/قاعدة البيانات وليس الواجهة فقط
- سجل تدقيق للعمليات الحساسة
- إضافة الخدمات مستقبلًا كوحدات مستقلة
